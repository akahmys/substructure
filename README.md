# Substructure

AIエージェントに、プロジェクトの初期準備（フォルダ作成・ルール設定・タスク整理）を実行させるための指示書です。

この指示書を直接AIに読ませるだけで、面倒なフォルダ作成からルール構築までを完了させます。

---

## 使用条件

Claude Codeなどの、フォルダやファイルを作成・操作できるAIエージェント専用です。

ChatGPTなど、チャット画面だけでファイルを操作できないAIでは使えません。

---

## 開発の背景

巷にあふれる「超入門」をいちいちコピペしたり、フォルダをちまちま作成するのは、最も遠回りなAI活用法です。

---

## 使い方

作業用のフォルダを作成して、その直下で以下の依頼をしてください。

```text
[ここに指示書URL] この通りに準備して。
```

不満なことなどがあれば以下の依頼をしてください。

```text
ルールを改善して。
```

### 指示書URL

用途に合わせて、以下のURLを使ってください。

* **基本バージョン**（開発・リサーチ・一般プロジェクト向け）
`https://raw.githubusercontent.com/[あなたのGitHubユーザー名]/Substructure/main/agents/basic.md`

* その他は作成中
