# Substructure プロジェクト開発用ガイドライン

本ファイルは、`Substructure` プロジェクトのコードや指示書テンプレートを編集・拡張するAIエージェント（および開発者）向けの共通ルールです。

## 1. プロジェクトの概要と目的
* **目的:** AIエージェントがプロジェクトの初期準備（ディレクトリ構築・ルール設定・タスク整理）を自律的に行うための指示書テンプレートの開発・メンテナンス。
* **ターゲット:** Claude Code などの物理的なファイル・フォルダ操作が可能なAIエージェント。

## 2. 開発・メンテナンス方針
* **指示書の明確性:** テンプレートファイル（例: `basic.md`）は、AIエージェントが誤解なく一発で解釈できるよう、具体的かつ指示内容に曖昧さのない簡潔な日本語で記述してください。
* **指示書の拡張:** 今後、Web開発特化、データ分析特化、執筆特化などの用途別指示書を追加する場合は、`instructions/` ディレクトリ直下に `[用途名].md` の形で配置してください。
* **README.mdの更新:** 新しいテンプレートを追加した際は、必ず `README.md` にその用途と GitHub の raw リンクを追加し、ユーザーが簡単にコピーして使えるようにしてください。

## 3. 安全・禁止ルール
* **既存テンプレートの破壊的変更の禁止:** すでに稼働している `basic.md` などのテンプレートの基本構造（タスク1〜3の定義や安全ルール）を独断で削除・変更することは避けてください。仕様変更が必要な場合は、必ずユーザーに確認の上で実施してください。
* **安全ルールの継承:** すべての派生テンプレートにおいて、「マスターデータの保護」や「物理データの削除禁止」といった安全ルールを必ずデフォルトで盛り込むようにしてください。

## 4. 報告スタイル
ユーザーに提案や変更の報告を行う際は、以下の構成を意識してください。
1. 編集・追加したテンプレート名と、その変更意図
2. ユーザーがそのテンプレートを即座に試すための指示用URL（Raw URL）
3. 次の具体的なステップ
